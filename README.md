# Работа с Git Bash


| Раздел | Что внутри |
|---|---|
| bash1 | Навигация и директории, Управление файлами, Работа с содержимым |
| bash2 | Поиск и обработка текста, Управление процессами, Сеть и работа с API |


**Итог:** освоены базовые навыки работы в Git Bash: управление файлами и директориями, 
поиск и редактирование текста (grep, find, sed), контроль системных процессов (ps, kill), 
проверка сети (ping) и отправка API-запросов через curl.
